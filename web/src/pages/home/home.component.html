Build blazing fast
web apps with Rust

Ferric is a modern web framework combining Rust's safety and performance with WebAssembly. Build reactive, component-based applications that run at native speed.

Get Started View on GitHub
counter.rs 
use ferric::prelude::*;

#[component]
fn Counter() -> impl View {
    let count = signal(0);

    view! {
        <div class="counter">
            <h1>"Count: " {count}</h1>
            <button on:click=move |_| count.update(|n| *n + 1)>
                "Increment"
            </button>
        </div>
    }
}

Why Ferric?

Designed from the ground up for modern web development

⚡

Lightning Fast

Compile to WebAssembly for near-native performance. No JavaScript overhead.

🦀

Rust Powered

Leverage Rust's memory safety and zero-cost abstractions.

🔄

Fine-grained Reactivity

Efficient updates with signals, computed values, and effects.

💉

Dependency Injection

Angular-inspired DI system for clean, testable architecture.

📦

Small Bundle Size

Tree-shakeable components with minimal runtime overhead.

🛡️

Type Safe

Get started in minutes

Create your first Ferric app with a single command

1

Install the CLI

cargo install ferric-cli
2

Create a new project

ferric new my-app
cd my-app
3

Start developing

ferric serve
