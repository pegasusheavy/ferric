Introduction

Ferric is a modern web framework for building reactive, component-based applications using Rust and WebAssembly. It combines the safety and performance of Rust with familiar patterns from frameworks like Angular and React.

With Ferric, you can build web applications that:

  • Run at near-native speed with WebAssembly
  • Catch errors at compile time with Rust's type system
  • Update efficiently with fine-grained reactivity
  • Scale cleanly with dependency injection

Why Ferric?

💡
Performance without compromise. Ferric compiles to highly optimized WebAssembly, delivering performance that JavaScript frameworks simply cannot match.

Traditional JavaScript frameworks suffer from inherent performance limitations: garbage collection pauses, dynamic typing overhead, and JIT compilation unpredictability. Ferric sidesteps all of these by leveraging Rust's zero-cost abstractions and compiling directly to WebAssembly.

Core Concepts

Components

Components are the building blocks of Ferric applications. Each component is a Rust struct that defines its own state and rendering logic.

my_component.rs 
#[component]
fn MyComponent() -> impl View {
    view! {
        <div class="my-component">
            <h1>"Hello, Ferric!"</h1>
        </div>
    }
}

Signals

Signals are reactive primitives that automatically track dependencies and trigger updates when their values change.

signals.rs 
// Create a signal with initial value
let count = signal(0);

// Read the value
let current = count.get();

// Update the value
count.set(1);

// Update based on previous value
count.update(|n| *n + 1);
