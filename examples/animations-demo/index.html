🎬 Ferric Animations

About

Ferric Animations is an Angular-inspired animation system for the Ferric framework. It provides a declarative API for creating smooth, performant animations using the Web Animations API.

  • Animation Triggers with named states
  • Smooth transitions with timing functions
  • Keyframe animations for complex sequences
  • Stagger animations for lists
  • Route animations
  • Builder API for fluent construction

Code Examples

// Create a fade animation trigger let fade = trigger("fade", vec![ state("hidden", vec![("opacity", "0")]), state("visible", vec![("opacity", "1")]), transition("hidden => visible", "600ms ease-in"), ]); // Use the builder API let slide = AnimationBuilder::new("slide") .state("left", vec![("transform", "translateX(-100%)")]) .state("center", vec![("transform", "translateX(0)")]) .transition("left => center", "400ms ease-out") .build(); // Create stagger configuration let stagger = StaggerBuilder::new(300, 50) .max_items(10) .reverse() .build();
